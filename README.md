# schemata-java

[![Test](https://github.com/nostrability/schemata-java/actions/workflows/test.yml/badge.svg)](https://github.com/nostrability/schemata-java/actions/workflows/test.yml)

Java data package for [Nostr](https://nostr.com/) protocol JSON schemas.

## Usage
```java
String schema = Schemata.get("kind1Schema");
List<String> keys = Schemata.keys();
```
